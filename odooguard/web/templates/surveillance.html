Avertissement : vide = 80 % du seuil critique, 0 = pas d'avertissement. Les deux seuils doivent dépasser l'intervalle entre deux exécutions planifiées, plus la durée d'une exécution ; sinon une alerte part entre deux passages normaux. Exemple : sauvegarde toutes les heures → avertissement 1,5 h, critique 2 h ; copie une fois par jour → avertissement 25 h, critique 26 h.

Services
